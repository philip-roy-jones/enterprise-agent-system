# Project instructions

- Use the name Enterprise Agent System. The platform supports multiple departments; Finance is the first example.
- Keep simulated model and staff runs explicitly labeled. Do not claim live-model evaluation without an actual verified live run.
- Learned skill packages may activate automatically after runtime-owned validation, as authorized in docs/plans/agent-led-learning-plan.md. The learner cannot alter admission rules or execute arbitrary generated Python. Business operations always require staff approval. Historical developer-reviewed proposals are not automatically deployed by this policy change.
