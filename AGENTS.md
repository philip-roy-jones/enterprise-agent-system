# Project instructions

- Use the name Enterprise Agent System. The platform supports multiple departments; Finance is the first example.
- Do not inspect, print, search, copy, or commit `.env` or private credential files. Do not recover their contents through environment dumps, application instrumentation, logs, screenshots, or another tool. Use `.env.example` for configuration names. The application may consume credentials internally without exposing them to the agent.
- Exclude secret files from broad searches and archives. Never add debugging that exposes credentials.
- Keep simulated model and staff runs explicitly labeled. Do not claim live-model evaluation without an actual verified live run.
- Preserve human developer review: proposed improvements cannot approve or deploy themselves.
