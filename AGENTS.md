# Project instructions

- Use the name Enterprise Agent System. The platform supports multiple departments; Finance is the first example.
- Keep simulated model and staff runs explicitly labeled. Do not claim live-model evaluation without an actual verified live run.
- Learned skill packages may activate automatically after runtime-owned validation. The learner cannot alter admission rules or execute arbitrary generated Python. The digital-employee lifecycle in docs/plans/digital-employees.md supersedes the earlier Strict-only execution policy: shadowing is observation-only, active employees execute under server authorization, and supervisors can pause or activate them. Historical approvals and teaching evidence must preserve their original provenance.
