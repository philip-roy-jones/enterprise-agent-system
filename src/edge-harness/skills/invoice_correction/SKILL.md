# Invoice correction

Use this skill for a request to prepare and save a correction draft. Do not use it for read-only reporting. The runtime binds the package to the installed worker's company, role and application version.

Read the skill, then invoke its workflow. Validate the assignment, open the assigned invoice, compare it with its purchase order, prepare the draft, save, independently verify the saved result, and complete. Staff must approve each operation separately.

Stop when scope, record identity or comparison evidence is uncertain. If the amount label changes, request supervised investigation and resume the same workflow after verifying its preconditions. Never repeat an uncertain Save; reconcile using the original operation identity. Completion is followed by staff outcome acceptance.
